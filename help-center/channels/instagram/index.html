    Instagram

    Link an Instagram professional account to a Facebook Page so you can create and run an Instagram channel bot in Add Process.

    Link an Instagram professional account to a Facebook Page so you can create and run an Instagram channel bot in Add Process.

    What the customer can accomplish

    Connect Instagram through Facebook credentials, choose the Facebook Page that owns the Instagram account, and finish creating an Instagram bot.

    Why it is useful

    Instagram bots in Add Process use Facebook Page–linked Instagram credentials. Without this link, the Instagram channel bot cannot be configured with a valid Facebook credentials id.

    Prerequisites

    • Access to the organisation in Add Process
    • Ability to connect Facebook (Instagram Facebook) integration credentials in the portal
    • An Instagram account that can be linked to a Facebook Page (Meta’s requirements apply)

    Where to find it

    In the app (start here):

    1. Configuration → Create bot (bots list): https://app.addprocess.pro/addprocess/bots
    2. Add or edit an Instagram bot
    3. In Instagram credentials, select / connect a Facebook account via the integration credentials selector
    4. Complete Meta’s connect flow; Add Process then returns you to an intermediate Select Facebook page step (OAuth return — see below)

    Integrations hub (manage credentials): https://app.addprocess.pro/integrations — open from the user avatar menu → Integrations.

    Do not open the Facebook page–selection screen as a standalone bookmark. It is an intermediate OAuth return step that depends on connect-session state. After you connect Facebook credentials from the Instagram bot form, the app redirects you there automatically to pick a Page.

    Step-by-step workflow

    1. Open the bots list and start Add bot (or edit an existing Instagram bot).
    2. Choose channel Instagram.
    3. Under Instagram credentials, use the Facebook account credentials selector to add or pick Facebook (Instagram Facebook) credentials.
    4. Complete the external Facebook/Instagram connection when prompted.
    5. When Add Process returns from OAuth, use the Select Facebook page screen to choose the Facebook Page that lists the correct Instagram username (links to instagram.com/{username} are shown per page).
    6. Confirm selection. On success the UI reports that the account was selected; on failure it shows an error and a Meta help link for connecting Instagram to a Page.
    7. Finish saving the Instagram bot in Add Process.

    Configuration options

    • Facebook credentials — required on the Instagram bot credentials form
    • Facebook Page — chosen on the OAuth return Select Facebook page step from pages returned for the connected account

    Exact Meta OAuth screens and business-manager settings are outside Add Process; treat provider UI details as unverified beyond what the Portal shows.

    Expected result

    • Instagram bot credentials store a Facebook credentials id
    • A Facebook Page (with linked Instagram) is selected
    • The bot appears in the bots list and can be used in a bot assignment

    Limitations

    • Instagram assignments do not enable the welcome-dialog or slash-commands editors (triggers still apply)—see Bot assignments.
    • The Select Facebook page step is part of the OAuth return flow only; opening it without that session state will not work.
    • Meta account/Page eligibility is controlled by Facebook/Instagram, not by Add Process.
