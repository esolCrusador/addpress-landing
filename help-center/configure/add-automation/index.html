    Add automation

    Design conversational automations — messages, branching, surveys, and reminders — in a list or canvas editor.

    Design conversational automations (scenarios, reusable modules, and reminders) in a list or canvas editor, then start them from menus, bot assignments, or chat tools.

    Application navigation

    PageURL
    Automations listhttps://app.addprocess.pro/addprocess/scenarios
    Create automationhttps://app.addprocess.pro/addprocess/scenarios/new
    Scenario editorhttps://app.addprocess.pro/addprocess/scenarios/{scenarioId} — replace {scenarioId} with the automation id from the list

    In the app: side navigation → Configuration → Add automation.

    What it does

    • Create and maintain Scenario, Module, and Reminder module types.
    • Edit steps in List or Canvas mode.
    • Compose messaging, branching, nested modules, surveys, quizzes, HTTP/integrations, variables, AI dialog, menus, subscriptions, and more.
    • Reference reminder modules from message / AI dialog / quiz question steps (and a default reminder on the scenario when enabled).
    • Export / copy / import automations from the editor or list.
    • Hide items from pickers without deleting them (Hide unused entities).

    Who uses it

    Builders who design multi-step chat journeys, reusable subflows, and timed follow-up modules.

    UI guide

    List page (“Automations”)

    Header: title, Show hidden, Add Automation, Import.

    Grid of automations with edit, duplicate, delete, and hide actions (root items support hide). Opening a row loads the editor.

    Editor

    Top bar: automation name (or “Add automation” for new), Export, Copy, and save/cancel (on Canvas, submit actions sit in the top bar; on List, at the bottom).

    Properties row:

    • Name
    • Module type — Scenario, Module, or Reminder
    • Default reminder — when enabled for the type, pick a reminder module
    • Edit mode — List or Canvas
    • Optional AI prompt / agent and broadcasting checkboxes when those fields are enabled

    Steps area:

    • List mode — ordered step list with add/edit controls for supported blocks
    • Canvas mode — visual graph of steps; supports the Switch step (List mode does not)

    Save may offer Submit or Submit ignoring validation when the form is dirty but invalid.

    Building blocks (customer-facing groups)

    These are step types available in the builder (grouped as in the product). This is not a separate module guide per step.

    GroupExamples of what you can do
    MessagingMessage, resend, task, speech-to-text, AI dialog
    LogicalPause, switch (Canvas), for-each, set variable, get next item
    ModulesCall a module, module switch, parallel modules, show a menu, subscription create/update/delete
    SurveySurvey start, options, text answer, prefill, submit
    QuizQuiz start, question, finish
    IntegrationHTTP request, integration action (connected systems such as Sheets / AmoCRM / TourVisor when configured)

    Reminders: create a module with type Reminder, then select it on steps that expose a reminder field (e.g. message, AI dialog, quiz question) or as the scenario default reminder.

    Subscriptions: the Subscription step can Create, Update, or Delete a subscription to another module (with expressions for name/state/until/period as shown in the step form)—not a calendar product.

    How scenarios get started

    • Bot assignments — command, trigger, or (Web Chat) welcome action points at a scenario
    • Menus — a Scenario menu node
    • Scenario Menu step — show a menu mid-flow
    • Chat tools in the portal (e.g. start scenario from chat history) when available for operators

    Notes

    • List vs Canvas is a per-automation setting; switching modes may restrict which steps remain valid (notably Switch requires Canvas).
    • Reminder modules are not a separate calendar or appointment-booking product; they are automations selected as follow-up flows from steps.

    Build a conversational scenario

    Design flows in list or canvas mode: messages, pauses, branching, nested/parallel modules, HTTP, variables, speech-to-text, tasks, and more.

    What the customer can accomplish

    Author multi-step automations (Scenario / Module / Reminder types) that bots and menus can start.

    Why it is useful

    Structured journeys beyond single replies—onboarding, qualification, reminders, quizzes, integrations.

    Prerequisites

    • Access to Configuration → Add automation

    Where to find it

    PageURL
    Listhttps://app.addprocess.pro/addprocess/scenarios
    Editorhttps://app.addprocess.pro/addprocess/scenarios/{scenarioId}

    Step-by-step workflow

    1. Add Automation; set name and module type (Scenario, Module, or Reminder).
    2. Choose List or Canvas edit mode (Switch step requires Canvas).
    3. Add steps from messaging, logical, modules, survey, quiz, and integration groups.
    4. Optionally set default reminder, AI prompt/agent, broadcasting when enabled.
    5. Save (or submit ignoring validation when the UI offers it); wire from assignments/menus.

    Expected result

    A runnable automation selectable from bot assignments, menus, and operators’ start-scenario tools.

    AI-powered lead qualification workflows that help businesses convert more leads and never miss a sale.
