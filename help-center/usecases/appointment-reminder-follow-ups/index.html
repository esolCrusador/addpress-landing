    Appointment & reminder follow-ups

    Collect appointment details in chat and let reminder automations follow up later in the same conversation.

    Collect appointment-related details in a chat scenario, then use reminder modules (and optional subscription steps) so the bot can follow up later in conversation.

    Business problem

    Teams book interest or appointments in chat but forget to nudge the user. They need the same bot that collected details to run a follow-up automation later—not only a one-shot message.

    Target audience

    Service, sales, and support teams using Add Process bots who already run conversational scenarios.

    Customer journey

    1. User starts via menu, command, or trigger.
    2. A scenario asks for date preference, contact details, or other intake (messages and/or survey steps).
    3. The flow references a Reminder module (on a step or as the scenario default reminder) so a follow-up automation can run later according to product reminder behaviour.
    4. Optionally, a Subscription step creates/updates/deletes a subscription to another module for recurring-style follow-up inside the platform.
    5. User receives later bot messages from that reminder/subscription path; staff can review chat history.

    Step-by-step implementation

    1. Create a Reminder-type automation under Scenarios with the follow-up messages you want.
    2. Create the main intake Scenario (messages / survey steps as needed).
    3. On steps that support it (e.g. message, AI dialog, quiz question), select the reminder module—or set the scenario default reminder.
    4. If you need subscription create/update/delete behaviour, add a Subscription step and configure action + module (and expressions shown in the form).
    5. Activate a bot so users can enter the intake scenario (menu / command / trigger / Web Chat welcome).
    6. Test entry and that the reminder module is selected correctly; do not assume external calendar sync.

    Features involved

    • Build a conversational scenario
    • Reusable modules & reminders
    • In-chat survey (optional intake)
    • Activate a bot
    • Bot menu navigation (optional entry)

    Product areas involved

    • Scenarios
    • Reminders (module type inside Scenarios)
    • Bot assignments, Bots
    • Optional: Menus, Surveys

    Expected business outcomes

    • Intake and follow-up live in the same bot platform
    • Clearer “we’ll remind you” journeys without leaving chat
    • Operators can audit conversations in chat history

    Prerequisites and limitations

    Supported in product (document only this):

    • Reminder module type and selecting a reminder on supported steps / default reminder
    • Subscription step actions Create / Update / Delete toward another module
    • Collecting details via scenario messaging and surveys

    Not claimed (not evidenced as first-class Portal features):

    • Google Calendar / Outlook sync
    • Native appointment slot picker UI
    • SMS/email appointment products outside chat automations

    If you need calendar systems, that would require a custom Integration / HTTP design—treat as project-specific, not built-in appointment booking.
