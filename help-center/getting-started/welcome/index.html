    Welcome to AddProcess

    Build and run conversational bots and automations across Telegram, Instagram, and Web Chat, with AI agents and knowledge bases.

    AddProcess is a multi-tenant platform for building and running conversational bots and automations across Telegram, Instagram, and Web Chat, with AI agents, knowledge bases, menus, and lead tracking.

    How the product is organised

    The side navigation in the app follows the same structure as this Help Center.

    AreaWhat you do there
    ConfigureBuild menus and automations (scenarios), create channel bots, activate them, and set up Web Chat widgets
    AgenticAdd knowledge bases and knowledge scopes, store LLM provider credentials, and configure AI agents
    ChannelsConnect the places your customers talk to you: Web Chat, Instagram, and embedded chat widgets
    Chat HistoryBrowse conversations for a bot (opened from the bots list)

    Where to start

    1. Building your first chatbot: connect a channel bot and activate it with a welcome message or menu.
    2. Build your first AI Agent: add credentials, configure an agent, test it, and wire it into a bot.
    3. Browse Use cases for end-to-end recipes such as lead capture or website chat for conversion.

    Key building blocks

    • Create bot: create bots for Telegram, Instagram, and AddProcess Web Chat.
    • Activate bot: welcome dialog, commands, message and attachment triggers, and AI agent actions.
    • Add menu: hierarchical bot menus with buttons that start scenarios or open submenus.
    • Add automation: conversational scenarios built from steps.
    • Agents: AI agents with a prompt, model, and knowledge scopes.
    • Chat widget: embed Web Chat on your website.
